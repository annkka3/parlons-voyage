# Parlons Voyage

Французский для путешествий: 56 фраз на 10 дней, 1000 базовых слов в 20 темах, 12 уроков грамматики, диалоги, кроссворд, Wordle, числа и цены на слух. Интерфейс и подсказки на английском или русском, транскрипция IPA и кириллицей, озвучка голосом устройства.

Приложение открывается по адресу https://annkka3.github.io/parlons-voyage/ и ставится на домашний экран телефона как обычное приложение. После первого открытия работает без интернета.

## Как устроено

- `index.html` — оболочка, `css/style.css` — оформление, `js/` — логика (`core.js` повторения и синхронизация, `ui.js` экраны, `session.js` тренировка с подсказками, `games.js`, `crossword.js`, `wordle.js`, `lessons.js` + `grammar.js` уроки).
- `js/data.js` — 56 фраз, числа, диалоги. `js/vocab.js` — 1000 слов, создаётся скриптом `tools/make_vocab.py` из `tools/source/french_core_1000.json`, списков произношения `tools/ipa/` и таблицы эмодзи `tools/emoji.txt`.
- `store.js` — вход по почте и паролю и синхронизация через Firebase (Auth + Firestore). `config.js` — настройки Firebase.
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим и установка на домашний экран.
- `vendor/` — библиотеки Firebase лежат рядом, чтобы работать без сети.
- `firestore.rules` — правила доступа: каждый человек видит и меняет только свою ветку `users/<его id>/…`.

## Звук и проверка голосом

Все французские тексты приложения (фразы, слова, примеры уроков, решения упражнений, реплики диалогов, числа) озвучены заранее французским голосом Thomas с macOS и лежат в `audio/` (около 22 МБ, имя файла — хеш текста). Запись воспроизводится как обычный звук, поэтому играет и при беззвучном режиме iPhone, чего голос устройства не умеет. Тексты без записи и режим «Выкл» в «Я» → «Звук в беззвучном режиме» используют голос устройства. Кнопка «Скачать весь звук» в «Я» сохраняет все записи для работы без интернета.

Записи создаются на Mac: `node tools/audio_texts.js && python3 tools/make_audio.py` (нужны `say` и `afconvert`; уже сделанные файлы пропускаются, список `js/audio-manifest.js` обновляется сам). Голоса macOS принадлежат Apple: записи сделаны для личного обучения, для коммерческого распространения их нужно заменить.

Фразы можно говорить вслух и сверять с ответом самой, а в браузерах с распознаванием речи (Safari и Chrome во вкладке) есть кнопка «Проверить голосом». В приложении с домашнего экрана iPhone распознавание речи не работает, кнопка там не показывается.

## Грамматика

«Курс на год» (A1–B2): 72 темы, 216 примеров, 288 тренировочных и 40 контрольных заданий, план на 52 недели, справочник терминов и 25 глаголов. Содержимое лежит в `data/grammar_course.json` и читается без изменений; перед использованием файл проверяется (код курса, версия схемы, уникальность ID, ссылки на предыдущие темы, типы заданий). Правила проверки ответов: Unicode NFC, прямой и типографский апостроф равны, регистр и конечная пунктуация не важны, акценты важны (`a` и `à` разные ответы). Подсказка и показанный ответ не считаются самостоятельным успехом, открытые задания оцениваются самой, контрольные задания не попадают в ежедневные подходы, уровень CEFR приложение не присваивает. Прогресс (`S.gc`) хранится вместе с остальным и синхронизируется документом `fr_meta/gc`. «Быстрые уроки» (12 штук на двух языках) остались как краткий вариант.

## Повторения

Пять коробок: 1, 3, 7, 14, 30 дней. Верный ответ без подсказок двигает карточку вперёд, ответ с подсказками оставляет на месте, ошибка отправляет в «трудный пул», откуда карточка выходит после двух чистых ответов подряд. Игры расписание не меняют.

## Синхронизация и несколько человек

Прогресс сначала сохраняется на устройстве, потом уходит в облако (по документу на карточку: `users/<uid>/fr_cards`, настройки и уроки: `users/<uid>/fr_meta/main`). Без интернета приложение работает, а накопленное отправляется, когда связь вернётся.

Каждый человек входит под своей почтой: прогресс не пересекается ни в облаке (правила Firestore), ни на общем телефоне (локальная копия хранится отдельно для каждого аккаунта, при выходе экран становится чистым). Новому человеку нужно открыть страницу и нажать «Создать аккаунт».

Сейчас приложение использует тот же Firebase-проект, что «Слайд-учёт» (`slide-uchet`): одна почта и пароль на оба приложения, правила уже опубликованы. Чтобы отделить проект, создайте новый в https://console.firebase.google.com, вставьте его `firebaseConfig` в `config.js`, включите Authentication → Email/Password, создайте Firestore и опубликуйте `firestore.rules`.

Если в проекте отключена регистрация (Authentication → Settings → User actions → Enable create), новых людей добавляют вручную: Authentication → Users → Add user.

## Обновление

Изменения публикуются командой `git push` в ветку `main`, страница обновляется через минуту-две. При смене списка файлов оболочки поднимите `VERSION` в `sw.js` и добавьте файл в `CORE`.

Если нужно поменять слова: правьте `tools/ipa/*.txt` и `tools/emoji.txt`, затем `python3 tools/make_vocab.py`.

## Резервные копии

Меню «Я» → «Сохранить файл копии» сохраняет прогресс в `.json`. Загрузить копию обратно можно кодом на том же экране.
